The photographic 3D of the planet is delivered by Cesium, free for personal and evaluation use. It asks for a token: a long password that only lets this page read map tiles. It cannot spend money or touch your account. If you ever worry, you delete it on the same website in one click.
  1. Open ion.cesium.com and create a free account.
  2. Go to Access Tokens and press Create token (the defaults are fine).
  3. Copy the token and paste it below. It stays only in this browser.
